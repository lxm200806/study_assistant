# 主题色分层（分析与约定）

改主题不能只改页面底色。按钮、卡片、轨道、选中态、危险态都要跟着变。  
**当前完整适配：日间·米色、夜间·墨灰。** 其它官方主题有基底色，分层同结构但未精细校对。

## 各标签页里常见落点

| 页面 | L0 | L1/L2 | 按钮/chip | 系统弹层 |
|------|----|-------|-----------|----------|
| 认读 | `.desk` | 进度轨道、选项卡、反馈条 | `.start` `.chip.on` `.ghost` | `uni.showToast`（系统，难改） |
| 拼读 | `.desk` | 同认读 + 等级条 | 同认读 | Toast |
| 词书 | `.container` | `.book-card` 白卡片 | 选中描边、会员弹窗 | `showModal` |
| 图鉴 | `.atlas-page` | `.desk-card`、分段 | 分段选中 | Modal |
| 主题 | `.container` | `.section` 白卡片 | 添加按钮 | Modal/Toast |
| 侧栏 | rail | hover/on | — | 角色切换浮层 |

## 改主题时的规则

1. **禁止**只改 `--pc-main-bg` / `--pc-rail-bg` 就当完成。  
2. 业务页根与控件优先用上表变量；新增 UI 不要写死 `#fff` / `#000` / 高对比紫按钮。  
3. 夜间原则：卡片略亮于画布（L2 > L0），主按钮用柔和 accent，避免白卡片+黑字硬贴深底。  
4. `uni.showModal` / `showToast` 为系统组件，H5 上几乎无法跟主题；重要确认尽量用页内面板。

## 代码入口

- 色板与 apply：`src/utils/pc-theme.ts`
- 默认变量：`src/App.vue` `:root`
- 页面消费：认读/拼读等 `var(--pc-*)`
