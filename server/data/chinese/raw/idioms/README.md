# 小学成语数据

本目录采用“唯一词条 + 分题型题卡 + 自动生成发布包”的结构。

## 文件

- `小学成语.json`：1843 个已校准的唯一成语词条，只维护成语名称、拼音、释义、出处、标签和分层。
- `小学成语_题卡_背诵.json`：释义提示与背诵题卡。
- `小学成语_题卡_拼音.json`：看成语选正确拼音，干扰项为多音字误读、调号和常见声韵母混淆。
- `小学成语_题卡_易错字选择.json`：四选一的规范写法题卡。
- `小学成语_题卡_语义理解.json`：选择正确释义。
- `小学成语_题卡_语境选择.json`：根据句子语境选择成语。
- `小学成语_题卡_使用正误.json`：判断成语在句子中的使用是否恰当。
- `generated/小学成语_发布包.json`：自动合并的兼容发布包，禁止手工修改。
- `archive/停用待校准词条.json`：不进入发布包的旧短语、残缺表达、错写词和缺少可靠依据的条目。
- `拼音核验记录.json`：联网交叉核验范围、来源和纠错记录。

题卡通过 `entry_key` 引用唯一词条，不重复保存年级、释义、出处和分层等公共信息。

易错字选择题沿用原 `:char_judge` 题卡 `key`，这是为了保留已发布题卡 ID 和学生历史复习记录；实际题型以 `question_type: "spelling_choice"` 为准。

`pinyin_review` 为 `web-cross-checked-2026-09-11` 表示已用公开网络资料交叉核对；`chinese-xinhua-unverified` 表示仍沿用抓取词典数据，尚未经过正版《新华成语词典》第2版人工核验。

## 分层

内部兼容值和界面名称：

- `primary`：基础
- `xiaoshengchu`：拓展
- `junior`：培优

成语不再设置年级或年级适用范围。年级筛选只影响古诗文、名句等其他语文内容。

## 维护流程

1. 修改唯一词条或对应题型文件。
2. 在 `server` 目录运行 `npm run build:idioms` 生成发布包。
3. 运行 `npm run audit:idioms`，必须保持零错误。
4. 通过后台“同步全部”或资源同步接口发布到数据库。

新增题型时应新增独立题卡文件，并同步补充题型常量、前端答题组件、评分与审计规则。
