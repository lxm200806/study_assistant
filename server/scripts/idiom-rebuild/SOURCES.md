# 成语题卡资料与分层依据

检索日期：2026-09-10

## 释义与词频

- [chinese-xinhua 成语数据](https://github.com/pwxcoo/chinese-xinhua)：提供词条、拼音、释义、出处和例句。释义经人工/模型逐条改写为适龄现代汉语，不直接作为最终题面。
- [THUOCL 成语词表](https://github.com/thunlp/THUOCL)：仅用于辅助判断常用程度，不能单独决定分层。
- 部编版教材出处：原题库中标注为部编版课文或日积月累的词条，优先归入“基础”。

- [天津市和平区 2024 年小升初语文试卷](https://www.renrendoc.com/paper/516680860.html)
- [天津市津南区 2024 年小升初语文试卷](https://www.51jiaoxi.com/doc-18133560.html)
- [上海六年级（五四制）词语与成语衔接资料](https://www.zxxk.com/soft/46207684.html)

这些样本用于校准题型和难度，不把聚合网站标题直接当作官方出处，也不把模拟卷误标为真题。

样本共同特征：

1. 小学阶段重字形、补全、浅显词义和简单语境。
2. 小升初重语境运用、近义辨析、褒贬色彩、适用对象和典故。
3. 公开试卷中出现过“万像更新”“见微知箸”“不可思义”“迫不急待”等典型误写；易错字选择题优先复用这些真实易错模式。
4. 试卷不会覆盖词库全部 2021 条成语，因此其余词条依据教材、词典和词频综合分层，不能声称来自某地真题。

## 二期考试型题卡

- `context_choice`：用校园、家庭、阅读和公共生活场景考查语境匹配，四个选项保持同一难度。
- `usage_judge`：考查词义、适用对象、褒贬色彩和固定搭配；每题附简短解析。
- 题型依据上述公开试卷的命题方向，但题干为独立创作，不复制整道试题，也不把模拟题标成真题。
- 所有基础、拓展考试型题卡须经过逐题内容审核与脚本审计后才可同步。

## 分层标记

- `primary`（基础）：部编教材词条，或高频且词义浅显、使用对象清楚的常用成语。
- `xiaoshengchu`（拓展）：常用但需要语境、褒贬、近义辨析或典故知识的成语。
- `junior`（培优）：低频、生僻、文言色彩重，或主要用于较复杂成人语境的成语。

成语本身不再绑定年级、学期、L1–L4 或低/高年级受众；教材和试卷只作为出处及分层依据。
