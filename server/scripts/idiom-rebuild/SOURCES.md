# 成语题卡资料与分级依据

检索日期：2026-09-10

## 释义与词频

- [chinese-xinhua 成语数据](https://github.com/pwxcoo/chinese-xinhua)：提供词条、拼音、释义、出处和例句。释义经人工/模型逐条改写为适龄现代汉语，不直接作为最终题面。
- [THUOCL 成语词表](https://github.com/thunlp/THUOCL)：仅用于辅助判断常用程度，不能单独决定学段。
- 部编版教材出处：原题库中标注为部编版课文或日积月累的词条，优先归入“小学”。

- [北京六年级下册词语和成语期末真题分类汇编](https://www.zxxk.com/soft/33652912.html)
- [北京六年级上册词语运用真题汇编](https://www.zxxk.com/soft/48398087.html)
- [北京市海淀区 2024—2025 六年级下册期末试卷](https://www.doc88.com/p-28468118201648.html)
- [天津市和平区 2024 年小升初语文试卷](https://www.renrendoc.com/paper/516680860.html)
- [天津市津南区 2024 年小升初语文试卷](https://www.51jiaoxi.com/doc-18133560.html)
- [上海六年级（五四制）词语与成语衔接资料](https://www.zxxk.com/soft/46207684.html)

这些样本用于校准题型和难度，不把聚合网站标题直接当作官方出处，也不把模拟卷误标为真题。

样本共同特征：

1. 小学阶段重字形、补全、浅显词义和简单语境。
2. 小升初重语境运用、近义辨析、褒贬色彩、适用对象和典故。
3. 公开试卷中出现过“万像更新”“见微知箸”“不可思义”“迫不急待”等典型误写；字形判断题优先复用这些真实易错模式。
4. 试卷不会覆盖词库全部 2021 条成语，因此其余词条依据教材、词典和词频综合分级，不能声称来自某地真题。

## 难度标记

- `primary`（小学）：部编教材词条，或高频且词义浅显、使用对象清楚的常用成语。
- `xiaoshengchu`（小升初）：常用但需要语境、褒贬、近义辨析或典故知识的成语。
- `junior`（初中）：低频、生僻、文言色彩重，或主要用于较复杂成人语境的成语。
